A LITTLE CORNER — MAIRA'S BIRTHDAY WEBSITE

FILES
- index.html: page structure and editable wording
- style.css: colours, layout, typography and mobile styling
- script.js: interactive little-note jar
- images/: add photographs here when we're ready

PREVIEW
1. Keep all these files together in the a-little-corner folder.
2. Open index.html in Microsoft Edge (right-click > Open with > Microsoft Edge).
3. The website runs locally on your computer. It is not published online.

CUSTOMISING
- Change the text in index.html to edit headings, captions and the birthday message.
- Change the notes array in script.js to edit the little-note jar.
- Replace the photo placeholders in index.html with your images when ready.

PRIVACY NOTE
The page includes a noindex instruction to discourage search engines from listing it. This is not access control or a privacy guarantee. Anyone with the published URL may still be able to visit it.
